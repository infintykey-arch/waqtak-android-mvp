# وقتك — Android MVP

نسخة Android أصلية أولية باسم **وقتك — منبّه المذاكرة**، بهوية زرقاء/فضية/داكنة وشعار شاشة البداية المعتمد. المشروع مخصص لهواتف وأجهزة Android اللوحية؛ لا يتضمن iOS أو Windows أو Mac.

## ما يتضمنه التطبيق

- بطاقات كورسات مربعة تتكيف مع مساحة الجهاز: عمودان على الهاتف، وثلاثة أو أربعة على الشاشات الأوسع. يمكن إضافة البطاقات وتعديلها وحذفها وتكبير عرضها.
- حفظ محلي للبطاقات وروابط عامة تبدأ بـ HTTP أو HTTPS (مثل روابط Coursera أو مواقع أخرى)، أو فيديو من الجهاز، إلى جانب وقت التنبيه وأيام تكراره خلال الأسبوع ومدة المذاكرة ولون البطاقة والتقدم اليومي وسلسلة الإنجاز. تظل البطاقات القديمة مضبوطة على كل أيام الأسبوع افتراضيًا.
- جلسة مذاكرة تعرض فيديوهات YouTube والروابط العامة داخل بطاقة WebView صغيرة متى سمح الموقع بالتشغيل المضمن؛ قد تحجب بعض المواقع التشغيل أو تتطلب تسجيل دخول. يمكن إيقاف احتساب الوقت واستئنافه، ويظهر زر نبضي عند اكتمال المدة، ولا تُسجّل المهمة مكتملة إلا عند الضغط عليه.
- زر «+» داخل الجلسة يوقف فيديو YouTube أو الفيديو المحلي ويفتح ملاحظات الكورس؛ يمكن حفظ عدة ملاحظات بعنوان اختياري، وتظل محفوظة محليًا بعد إغلاق الجلسة.
- إذا أُغلقت الجلسة قبل تأكيد الإكمال، يعود التنبيه بعد خمس دقائق كتذكير آلي مستقل عن حد التأجيلات اليدوية الثلاثة يوميًا. يمكن إضافة ملاحظات متعددة لكل كورس وتصدير الملاحظات المحددة إلى PDF.
- تنبيه Android أصلي في الأيام التي يحددها المستخدم، مع إشعار عالي الأولوية وشاشة منبه فوق شاشة القفل وخياري «ابدأ الآن» و«تأجيل ٥ دقائق». يعاد ضبط التنبيهات بعد إعادة تشغيل الجهاز أو تغيير الوقت.
- تشغيل صوت التنبيه عبر خدمة تشغيل أمامية مستمرة كي يبقى مسموعًا عند انتقال التطبيق إلى الخلفية أو قفل الشاشة، ويتوقف عند بدء الجلسة أو تأجيل المنبه.
- قسم لاختيار نغمة الإشعار من النغمات المتاحة على الجهاز، مع معاينتها وحفظها لاستخدامها مع التنبيهات في الأيام المحددة.
- إعلانات AdMob: بانر متكيّف أعلى محتوى الصفحة الرئيسية، وإعلان مدمج واضح التسمية بعد كل أربع بطاقات. يظهر الإعلان البيني بعد ضغط «إنهاء الجلسة» أو عند إيقاف فيديو محلي مؤهلًا، مع الحفاظ على حد إعلان واحد لكل فعلين للمستخدم وفاصل دقيقتين بين مرات الظهور. لا تُعرض إعلانات وقتك أثناء تشغيل يوتيوب، ولا تظهر على شاشة رنين المنبه أو شاشة القفل.

## معرفات AdMob

أُضيفت معرفات AdMob التي زودني بها المستخدم إلى `app/src/main/res/values/strings.xml`: معرّف التطبيق، وحدة البانر، الوحدة المدمجة (Native)، والوحدة البينية (Interstitial). المعرفات غير سرية؛ لا يلزم تعديلها لبناء نسخة الاختبار الحالية.

## حالة المصدر وبناء APK

إصدار المصدر الحالي هو `0.1.20` برقم إصدار `versionCode 21` للحزمة `com.wirdi.app`. يتضمن شريط الجلسة القابل للإرجاع مع حد يمنع التقديم بعد أعلى نقطة مسجلة، ومؤقتات إضافية متسلسلة، وإشعار متابعة هادئًا واحدًا بعد جلسة غير مكتملة بخياري المتابعة الآن أو الانتظار حتى موعد المنبه الدوري التالي. يعرّف تضمين YouTube التطبيق عبر عنوان أساس HTTP(S) ومعلمة `origin` مشتقين من معرّف الحزمة، مع سياسة إحالة `strict-origin-when-cross-origin`؛ ويظل تشغيل روابط المواقع العامة داخل WebView خاضعًا لما يسمح به كل موقع. تُبنى نسخ Release بالمفتاح الدائم نفسه. ملف `.jks` وكلمات المرور غير موجودة ضمن ملفات المستودع.

إعداد Gradle يقرأ بيانات التوقيع من متغيرات البيئة `MIDAD_RELEASE_STORE_FILE` و`MIDAD_RELEASE_STORE_PASSWORD` و`MIDAD_RELEASE_KEY_ALIAS` و`MIDAD_RELEASE_KEY_PASSWORD`. لا تُحفظ كلمة المرور أو نسخة المفتاح ضمن ملفات المشروع.

## أذونات Android 13/14+

يلزم السماح بإشعارات التطبيق، وجدولة المنبهات الدقيقة، وباستخدام Full-screen intent على Android 14+ كي تكون تجربة شاشة القفل موثوقة. يوفر التطبيق زر إعداد الأذونات؛ لا يمكن للتطبيق تجاوز خيارات النظام أو ضمان العرض الكامل إذا رفضها المستخدم أو قيّدها الجهاز أو الشركة المصنّعة.

## اللغات واتجاه الشاشة

تتوفر واجهة عربية وإنجليزية عبر موارد Android الأصلية. تتبع الواجهة لغة الجهاز، وتتيح قائمة لغات التطبيق في إعدادات Android 13+ اختيار العربية أو الإنجليزية؛ على الإصدارات الأقدم يتبع التطبيق لغة الجهاز. تتبدل اتجاهات RTL/LTR تلقائيًا، بما يشمل الشاشات المبنية برمجيًا ورسائل التنبيه والإشعارات.
