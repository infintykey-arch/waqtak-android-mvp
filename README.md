# وقتك — Android MVP

نسخة Android أصلية أولية باسم **وقتك — منبّه المذاكرة**، بهوية زرقاء/فضية/داكنة وشعار شاشة البداية المعتمد. المشروع مخصص لهواتف وأجهزة Android اللوحية؛ لا يتضمن iOS أو Windows أو Mac.

## ما يتضمنه التطبيق

- بطاقات كورسات مربعة تتكيف مع مساحة الجهاز: عمودان على الهاتف، وثلاثة أو أربعة على الشاشات الأوسع. يمكن إضافة البطاقات وتعديلها وحذفها وتكبير عرضها.
- حفظ محلي للبطاقات، رابط فيديو يوتيوب منفرد أو قائمة تشغيل كاملة أو فيديو من الجهاز، وقت التنبيه وأيام تكراره خلال الأسبوع، مدة المذاكرة، لون البطاقة، والتقدم اليومي وسلسلة الإنجاز. تظل البطاقات القديمة مضبوطة على كل أيام الأسبوع افتراضيًا.
- جلسة مذاكرة بمؤقت يومي يمكن إيقاف احتسابه واستئنافه؛ مع تشغيل فيديو يوتيوب المضمّن أو فيديو محلي.
- تنبيه Android أصلي في الأيام التي يحددها المستخدم، مع إشعار عالي الأولوية وشاشة منبه فوق شاشة القفل وخياري «ابدأ الآن» و«تأجيل ٥ دقائق». يعاد ضبط التنبيهات بعد إعادة تشغيل الجهاز أو تغيير الوقت.
- تشغيل صوت التنبيه عبر خدمة تشغيل أمامية مستمرة كي يبقى مسموعًا عند انتقال التطبيق إلى الخلفية أو قفل الشاشة، ويتوقف عند بدء الجلسة أو تأجيل المنبه.
- قسم لاختيار نغمة الإشعار من النغمات المتاحة على الجهاز، مع معاينتها وحفظها لاستخدامها مع التنبيهات في الأيام المحددة.
- إعلانات AdMob: بانر أسفل الصفحة، وإعلان مدمج بعد كل خمس بطاقات (أو بعد القائمة إذا كان عدد البطاقات أقل من خمسة)، وإعلان بيني بعد إكمال جلسة المذاكرة فقط. لا يظهر الإعلان البيني على شاشة المنبه أو القفل.

## معرفات AdMob

أُضيفت معرفات AdMob التي زودني بها المستخدم إلى `app/src/main/res/values/strings.xml`: معرّف التطبيق، وحدة البانر، الوحدة المدمجة (Native)، والوحدة البينية (Interstitial). المعرفات غير سرية؛ لا يلزم تعديلها لبناء نسخة الاختبار الحالية.

## حالة بناء APK

إصدار Release الحالي `0.1.8` برقم إصدار `versionCode 9`، متوافق كتحديث للحزمة `com.wirdi.app` وموقّع بمفتاح الإصدار الدائم نفسه. يدعم مشغّل الفيديو المحلي اختيار السرعة، والضغط المطوّل لمضاعفة السرعة المختارة مؤقتًا ثم استعادتها عند الإفلات أو الإلغاء. يستخدم فيديو يوتيوب عناصر التحكم الأصلية فقط. يجب الاحتفاظ بملف المفتاح لاستخدامه في تحديثات الحزمة نفسها. فقدان المفتاح يمنع توقيع تحديث متوافق.

إعداد Gradle يقرأ بيانات التوقيع من متغيرات البيئة `MIDAD_RELEASE_STORE_FILE` و`MIDAD_RELEASE_STORE_PASSWORD` و`MIDAD_RELEASE_KEY_ALIAS` و`MIDAD_RELEASE_KEY_PASSWORD`. لا تُحفظ كلمة المرور أو نسخة المفتاح ضمن ملفات المشروع.

## أذونات Android 13/14+

يلزم السماح بإشعارات التطبيق، وجدولة المنبهات الدقيقة، وباستخدام Full-screen intent على Android 14+ كي تكون تجربة شاشة القفل موثوقة. يوفر التطبيق زر إعداد الأذونات؛ لا يمكن للتطبيق تجاوز خيارات النظام أو ضمان العرض الكامل إذا رفضها المستخدم أو قيّدها الجهاز أو الشركة المصنّعة.
